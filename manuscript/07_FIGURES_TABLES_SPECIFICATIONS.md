## FIGURE 1: Conceptual Framework

**Title:** Conceptual framework linking GroChain digital food trust components to household food security and dietary diversity in Ilorin Metropolis

**Type:** Path diagram (PowerPoint or draw.io)

**Layout:**

```
┌─────────────────────────────────────────────────────────────┐
│           GROCHAIN INTERVENTION COMPONENTS                   │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │QR Trace- │ │Digital   │ │BVN/      │ │USSD +    │       │
│  │ability   │ │Marketplace│ │Fintech   │ │Partner   │       │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘       │

        └────────────┴─────┬──────┴────────────┘
                           ▼
        ┌──────────────────────────────────────┐
        │         MEDIATING PATHWAYS            │
        │  • Farmer income ↑                    │
        │  • Market transparency ↑              │
        │  • Post-harvest loss ↓                │
        │  • Buyer trust ↑                      │
        └──────────────────┬───────────────────┘
                           ▼
        ┌──────────────────────────────────────┐
        │      FOOD SECURITY PILLARS (FAO)      │
        │  Availability │ Access │ Utilisation  │
        │              │ Stability│              │
        └──────────────────┬───────────────────┘
                           ▼
        ┌──────────────────────────────────────┐
        │           OUTCOME MEASURES            │
        │  HFIAS score (primary)                │

        household size, LGA, WASH index
```

**Caption:** Figure 1. Conceptual framework adapted from HLPE (2020) food systems typology and Home Economics household resource model (Anyakoha, 2007). GroChain components are hypothesised to influence household food insecurity (HFIAS) and dietary diversity (MDD-W) through income, transparency, loss reduction, and trust pathways.

## TABLE FORMATTING (World Nutrition)

- Number tables consecutively (Table 1, Table 2…)  
- Use horizontal lines only (no vertical gridlines)  
- Footnotes with superscript letters  
- Report percentages to one decimal; p-values to three decimals  
- Confidence intervals: 95% CI in parentheses
