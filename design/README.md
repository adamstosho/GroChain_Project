# GroChain Design

Single source of truth for everything brand- and design-related: logo, color, typography,
imagery, and the audit trail behind current decisions.

As of 2026-08-27 the **official logo** is the designed identity (globe + network + leaf +
chain), with masters in `design/03-brand-assets/logo/source/`. Live UI uses
`client/components/ui/grochain-logo.tsx` → `/logo-full.png` and `/logo-icon.png`, generated by
`client/scripts/generate-logos.js`. Homepage illustrations come from
`client/scripts/generate-illustrations.js`. Color: live source is `client/app/globals.css`
(forest `#166534`); `01-brand-guidelines/color/design-tokens.json` should mirror it.

## Structure

```
design/
├── 01-brand-guidelines/     ← the standing reference: what's canonical, right now
│   ├── brand-guidelines.md  ← start here
│   ├── logo/
│   │   ├── logo-usage-notes.md
│   │   └── source/          ← mirrors of the generated public/logo*.svg, for reference
│   ├── color/
│   │   ├── color-palette.md
│   │   └── design-tokens.json   ← machine-readable; mirrors client/app/globals.css — hand-synced, can drift, see below
│   └── typography/
│       └── typography.md
├── 02-audits/                ← dated, point-in-time reviews (never edit an old one — add a new one)
│   └── 2026-08-25-brand-design-system-audit.md   ← now three resolution rounds deep
├── 03-brand-assets/          ← the approved illustration set (not placeholders — this is what's live)
│   └── photography/
└── 04-templates/             ← social/deck/email templates (empty — nothing to standardize yet)
```

## How this stays trustworthy

- **`01-brand-guidelines/` is the only place "current" lives.** If a value here and a value in
  `client/` disagree, that's a bug to fix (in one direction or the other), not a judgment call.
- **`design-tokens.json` is hand-synced with `globals.css`, not generated from it — this is the
  one real remaining drift risk in the whole system.** It already happened once: the round-3
  contrast-audit fixes shipped to `globals.css` on 2026-08-25 without this file being updated in
  the same pass, and the gap wasn't caught until the next day. If you change a color in
  `globals.css`, update `design-tokens.json` and `color-palette.md` in the same sitting — don't
  trust "I'll sync it later."
- **`02-audits/` is append-only.** Each review gets a new dated file; don't rewrite history by
  editing an old audit as things change — write a new one, or add a dated resolution-log section
  to the existing one, and let prior entries stand as a record.
- **`03-brand-assets/photography/` holds the actual approved image set**, generated by
  `client/scripts/generate-illustrations.js` — these are live assets, not placeholders to be
  replaced later.

## Numbering

`01-`/`02-`/etc. prefixes exist purely to keep the top level in a stable, intentional reading
order (guidelines before audits before assets before templates) — they're not a versioning
scheme.
